# DEFINITION_OF_DONE.md

Una tarea se considera terminada cuando cumple todo lo siguiente:

- el alcance solicitado esta implementado y no excedido
- respeta los documentos maestros y contratos vigentes
- no deja logica critica escondida en frontend
- incluye actualizacion documental si el cambio altera contratos o alcance
- pasa validaciones tecnicas requeridas para la capa afectada
- deja trazabilidad de supuestos, riesgos o deuda tecnica aceptada
- puede ser revisada sin depender de contexto oral no documentado
